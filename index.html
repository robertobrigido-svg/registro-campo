    Mais opções

    Envio para o Drive

    O limite por tipo de conexão só funciona se o aparelho informar o tipo (Chrome no Android informa; iPhone não). Nesse caso, use "Wi-Fi e dados móveis".

    PDF de uma sessão

    Gera um relatório simplificado, com as fotos carimbadas e os comentários, e salva no celular para você encaminhar. Não vai para o Drive.

    Limpar o celular

    Apaga do celular só os registros que o Drive já confirmou. Eles continuam no Drive.
